# Решение проблем и ограничения

## Установка и компиляция

| Симптом | Что проверить |
|---|---|
| Package Manager не находит UniversalFSM | Сначала установите публичный Git URL FSM и сохраните обе явные Git-зависимости в манифесте. Зависимость с номером версии сама не предоставляет реестр пакетов. |
| Git URL не разрешается | Проверьте установку Git, доступность его для Unity, тег и сетевое соединение. Используйте публичные адреса из README. |
| Игровой код не видит типы пакета | Добавьте ссылки на обе сборки Runtime и нужные пространства имён. API редактора размещайте в сборке только для Editor. |
| Команда создания примера отсутствует | Импортируйте пример через Package Manager и исправьте ошибки компиляции. Его сборка Editor должна быть включена. |
| Предупреждение о минимальной версии | Пакет требует Unity 6000.5. Фактически проверенные версии указаны в отчёте. |
| Частицы примера розовые | Генератор выбирает шейдер встроенного конвейера или URP, с запасным шейдером спрайта. Назначьте материал частиц, совместимый с вашим конвейером. |

## Ошибки настройки и исполнения

| Симптом | Причина и решение |
|---|---|
| В профиле нет состояний | Назначьте определение, содержащее состояния. |
| Add Effect не работает | Сохраните профиль в папке Assets проекта; содержимое установленного пакета не является местом для создания ассетов. |
| Эффект срабатывает у другого состояния | Проверьте точные слой, состояние и определение профиля. Зеркала используют исходные ID внутри своего слоя. |
| После переименования состояния эффекты продолжают работать | Сопоставление использует стабильные ID, а не отображаемые имена. Это ожидаемо. |
| Доменное событие ничего не вызывает | Сравните регистрозависимый ключ и убедитесь, что драйвер подключён к нужной шине. Автоматическая привязка контроллера не подключает пользовательскую шину. |
| При повторном включении эффекты повторяются | Bind повторяет вход текущих состояний. Не назначайте одному жизненному циклу одновременно автоматическое и ручное управление. |
| Bind выдаёт ошибку на выключенном драйвере | Настройте и включите его до привязки. Не вызывайте Bind во время очистки. |
| Профиль ссылается на другое определение FSM | Назначьте определение реально созданной FSM контроллера. После её замены выполните привязку заново. |
| Состояние Animator не найдено | Используйте полный путь, например Base Layer.Run, правильный индекс слоя и контроллер с нужным состоянием. |
| Триггер не найден | Создайте параметр типа Trigger с точным именем. Bool с тем же именем не подходит. |
| Точка реестра не найдена | Назначьте реестр, уникальный точный ключ и необходимые target или Renderer. |
| ParticleCue требует подходящий пул | Используйте Validate Setup и Add Pool, затем задайте положительную вместимость до Play Mode. Ссылки на префаб должны совпадать. |
| Пул не инициализируется | Нужен ровно один незацикленный ParticleSystem без вложенных эмиттеров. Не вызывайте инициализацию дважды. |
| При нагрузке часть эффектов пропадает | Заполненные пулы частиц и силуэтов намеренно отбрасывают новые запросы. Измерьте одновременную нагрузку и увеличьте заданную вместимость. |
| Силуэт не создаётся | Назначьте исходный SpriteRenderer со спрайтом и положительную конечную длительность. |
| Остановка времени не действует | Проверьте активность драйвера, общий координатор, паузу и положительную итоговую длительность. Режим данных сигнала не подставляет заданную длительность при нуле. |
| Время неожиданно остаётся остановленным | Вызывайте SetPaused до записи масштаба времени системой паузы и явно восстанавливайте её исходное состояние. |
| После сброса оружие осталось видимым | Переключение объектов постоянно. Добавьте скрытие при выходе или входе в начальное состояние либо правило сброса игрового кода. |
| После сброса изменены состояние или триггер Animator | Они относятся к политике игрового кода; при необходимости сбрасывайте явно. |
| Останавливается звук другой системы | Выделите драйверу отдельный AudioSource: сброс останавливает все его однократные звуки. |

## Границы проверки

Инспектор драйвера проверяет ссылки и поддерживаемую структуру конфигурации. Он не воспроизводит звук, не отображает частицы, не проверяет каждый путь Animator и не доказывает игровое поведение. Запустите каждую привязку и путь сброса в Play Mode. Тесты пакета и статическая компиляция полезны, но имеют другие границы. Выполненные проверки записаны в [отчёте](Validation.md).

## Миграция существующих ассетов

- **С 0.2.0:** создайте профили, эффекты и настройку сцены заново по модели драйвера, профиля и эффектов 0.3.x. Автоматической миграции несовместимой схемы нет. Старые API директора, сервисов, универсальных дескрипторов и аренд ресурсов отсутствуют.
- **С 0.3.0 или 0.3.1:** начальное значение перечисления HitStopCue — Authored (0), поэтому существующие ассеты продолжают использовать заданную длительность. Для режима 0.3.2 выберите SignalPayload и передайте Duration в данных события игрового кода.
- При обновлении пакета сохраняйте исходные .meta и GUID скриптов. Публичная сборка сохраняет идентичность ассетов Runtime и Editor.

## Преднамеренные ограничения

Пакет не управляет перемещением, вводом, ИИ, боевыми правилами, моментом AnimationEvent, поведением камеры или часами FSM. Нет встроенных последовательностей и задержек эффектов, пула циклических или составных VFX, шейдерной вспышки, независимого управления высотой тона и отменой отдельных голосов, редактора профиля во время игры или рассылки из рабочих потоков. Нужные правила можно реализовать собственными компонентами сцены и адаптерами.

Профиль и эффекты настраиваются до привязки. Изменение конфигурации во время рассылки не поддерживается. Повторная привязка очищает эффекты и может повторить действия входа, поэтому планируйте её явно.
