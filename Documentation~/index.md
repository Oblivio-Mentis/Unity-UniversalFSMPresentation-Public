# Документация UniversalFSMPresentation

Presentation **0.3.2** связывает изменения состояний UniversalFSM **0.2.0** и доменные события с эффектами Unity. Начните с создаваемой демонстрационной сцены, затем настройте профиль своего персонажа.

1. [Начало работы](GettingStarted.md) — установка, импорт, привязка и первый эффект.
2. [Ассеты и компоненты](AssetsAndComponents.md) — все поля и вспомогательные компоненты.
3. [Справочник эффектов](CueReference.md) — девять встроенных типов.
4. [Порядок работы](AuthoringWorkflow.md) — инструменты инспектора и жизненный цикл исполнения.
5. [Практические примеры](PracticalExamples.md) — покой, бег, прыжок, атака и отклик на урон.
6. [Интеграция с игрой](Integration.md) — границы систем и обязанности игрового кода.
7. [Собственные эффекты](CustomCues.md) — расширение возможностей без изменения внутреннего кода пакета.
8. [Справочник API](API.md) — полный публичный интерфейс исполнения.
9. [Решение проблем](Troubleshooting.md) — диагностика, миграция и ограничения.
10. [Результаты проверки](Validation.md) — выполненные проверки и границы подтверждённой совместимости.
